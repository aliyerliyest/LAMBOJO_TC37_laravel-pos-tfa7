# Laravel POS TFA7

A Laravel POS account management application with customer and user account forms, validation, editing, and avatar upload.

## Features

- Create customer accounts
- Validate customer full name and email
- Edit customer accounts
- Create user accounts
- Validate unique usernames and email addresses
- Edit user accounts
- Upload user profile pictures
- Validate avatar file type and size
- Resize avatars to 300 by 300 pixels
- Convert avatars to WebP format
- Store avatars using Laravel's public disk
- Display uploaded avatars on the User Accounts page
- Show placeholder avatars when no image is uploaded

## Requirements

- PHP 8.2 or higher
- Composer
- Laravel 12
- XAMPP
- MySQL or SQLite
- GD PHP extension
